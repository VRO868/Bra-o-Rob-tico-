# Braco-Robotico-
Projeto Braço Robótico - Princípios de Robótica - PUCPR

  Projeto feito por Vinicius Rafael de Oliveira na matéria de Princípios de Robótica, consiste em construir e programar um braço robótico capaz de resolver o jogo "Torre de Hanoi", na qual deve-se levar as peças para o último pino sem colocar a maior sobre a menor e apena o contrário (menor em cima de menor).

  # Erro:
    O erro foi devidamente reconhecido, acabou não resolvido por conta do prazo de entrega do projeto, sendo: 
    - Erro de montagem, em que a base foi montada invertida, impossibilitando a garra de descer mais do que mostrado no vídeo, sendo necessário ajuda externa para o realizar a tarefa.
